## Installer

1. Ouvre le lien de téléchargement ci-dessus **depuis ton téléphone**.
2. Ouvre le fichier `MaGardeRobe.apk` téléchargé. Si Android le demande, autorise l'installation depuis cette source (navigateur ou gestionnaire de fichiers).
3. L'app « Ma Garde robe » apparaît avec une icône de cintre turquoise.

## Mettre à jour

L'app t'affiche un bandeau « Nouvelle version disponible » quand une version plus récente existe. Appuie sur **Télécharger**, puis ouvre le fichier : la nouvelle version s'installe par-dessus l'ancienne, **sans perdre tes données**.

Avant une grosse mise à jour, tu peux faire une sauvegarde : Profil, Données, Exporter mes données.

## Important

- Tes données restent uniquement sur ton téléphone. **Désinstaller l'app les efface.**
- Aucune donnée n'est envoyée en ligne. Internet sert seulement à vérifier s'il existe une nouvelle version.
